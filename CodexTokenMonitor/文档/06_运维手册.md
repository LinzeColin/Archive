# 运维手册

怎么把它跑起来、参数在哪调、报错了怎么办、都改过些什么。

## 一、怎么跑

改完机器平面，按顺序跑这三条，让人类平面刷新并过关：

```bash
python3 machine/tools/render_human.py            # 先渲染人类平面
python3 machine/tools/check_doc_budget.py        # 体积、中文、纯净三道门
python3 machine/tools/check_blocker_stop.py      # 阻塞重审门
```

## 二、参数在哪调

改一个参数要动哪个文件，都在这。为什么定这个值在 `02_系统架构.md`。

| 参数 | 当前值 | 改哪里 |
|---|---|---|
| 恢复入口 | `source/codex-usage-monitor` | 归档目录 |
| 用量快照 | `data/usage.sqlite.gz` | 归档目录 |
| 安全排除 | 运行时令牌 / 日志 / 字节码 / 凭证 | `BACKUP_SCOPE.md` |

## 三、报错了怎么办

| 遇到什么 | 为什么 | 怎么解决 |
|---|---|---|
| 恢复后命令不可执行 | 脚本缺可执行权限 | 对 `codex-usage` 与相关脚本执行 `chmod +x`。 |
| 测试失败 | 运行环境缺依赖或路径不符 | 先 `python3 -m py_compile`，再 `python3 -m unittest discover -s tests`。 |
| 看不到用量 | 本机服务未装或令牌未在本机重建 | 按 `RESTORE.md` 重装 `LaunchAgent` 与菜单栏插件，并在本机重建访问令牌。 |
