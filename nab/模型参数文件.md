# 模型参数文件

本 surface 不包含评分模型、财务公式或自动决策参数。Cloudflare 运行参数如下：

| 参数 | 值 | 逻辑 |
|---|---|---|
| `worker_name` | `nab` | 固定 Worker 标识 |
| `compatibility_date` | `2026-07-10` | 本次 L2 兼容配置日期 |
| `assets.directory` | `./public` | 只发布公开静态目录 |
| `assets.not_found_handling` | `single-page-application` | 未知路径回退主页 |
| `compatibility_level` | `L2` | static-first public archive adapter |
| `private_data_allowed` | `false` | 硬性发布边界 |
| `external_actions_enabled` | `false` | 无写入或外部账户动作 |
| `preferred_domain` | `https://nab.linzezhang.com` | 已验证 custom domain |
| `workers_dev_url` | `https://nab.linzezhang35.workers.dev` | 已验证 Worker URL |
