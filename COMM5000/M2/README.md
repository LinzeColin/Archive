## 2. 必须沿用的清洗口径（M1 表 1，改了就和 M1 对不上）

- 豪华 = Audi、BMW、Mercedes；先 `TRIM` 品牌再分组。
- Fuel_Type 统一大小写并合并拼写（electrik→Electric，hybridd→Hybrid）。
- Unknown 保留为独立类别，不当缺失值删掉。
- 公里数上限 1,000,000：超出只在公里数分析里剔除（剩 998,866 行）。
- 技术参数（油耗、排量、马力）为 0 或超出均值 ±3 标准差：只在该字段设为空，整行保留。
- 疑似重复：15 个非随机字段都相同的行有 31,575 对，纯属巧合的期望约 26,821 对（按 13 个字段的类别占比计算），标记后保留。
- 价格极端值（对数尺度 3 倍四分位距外，低 1 个、高 2 个）和 ±3 标准差以内的孤立值：保留。
